# voluntrack

VolunTrack. connect. contribute. grow.
2025 by Shlok Jaiswal and Ayaan Ladak.

VolunTrack is currently on pause as a project. This repository was created as a way to document the progress of the site until it becomes monetized or resumes.

The version shown here is not the version displayed on the website (tinyurl.com/voluntrackbeta).
There is also more information on the teaser website which is formatted through Framer (voluntrack.framer.ai).
The repo for this project is updated every few days. To be updated immediately, reach out privately to voluntrack.beta@gmail.com.
VolunTrack was primarily coded using StackBlitz and the frontend was partially designed through bolt.new (a product from StackBlitz).
The backend (database) is supported by Supabase and the project was and for the near future will be deployed through Netlify.

Upcoming Features:
- Working database integration
- Hours logging
- Profile updating
- Messages supported by backend (Working messages)
- Organizations can finally be created and VolunTrack will have a small number of users testing it for us.
